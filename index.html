1. STYLE MASTER — ADD STYLE & OPERATIONS

Select a style below and manually add its operations + SAM, or import the selected style's operations from Excel.

Excel columns: Style No, Operation, SAM, Required Qty. Required Qty tells how many operators are needed for that operation on the line.

2. OPERATOR SKILL & EFFICIENCY — EXCEL IMPORT

Excel columns: Operator ID, Operator Name, Operation, SAM, Efficiency % — .xlsx, .xls and .csv supported

ADD OPERATOR MANUALLY

IDNameOperationSAMEfficiency %Action

3. DAILY ATTENDANCE — EXCEL IMPORT

Excel columns: Operator ID, Present (YES/NO). Present and absent counts are shown; only present operators are used for balancing.

4. LINE SETUP

Add any number of lines. SAM is taken from the selected Style Operations; no SAM field is required here.

5. AUTO LINE BALANCING

Balance all lines that have a Style selected. Operators are matched by Operation + SAM. Required Qty creates that many operator slots. Present operators only are used. Each Operator ID is allocated once.

6. FINAL OPERATOR ALLOCATION
